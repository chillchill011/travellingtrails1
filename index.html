JOB CAMPAIGN EXPLORER

Private job-search assistance with human control.

Job Campaign Explorer (JCE) helps authorized users organize job campaigns, review matched vacancies, prepare application material, create Gmail drafts, and receive Telegram notifications. It does not automatically send application emails or submit job applications.

What JCE does

Job campaigns

Users define candidate-specific search preferences and review discovered opportunities in a private application.

Gmail drafts

With the user's Google authorization, JCE can identify the connected Gmail account, reconcile existing drafts, and create or update application drafts for the user to review.

Telegram notifications

JCE can send candidate-specific job notifications through an explicitly configured Telegram bot. Telegram is notification-only.

Human-controlled applications

Users decide whether to edit, send, skip, or submit an application. JCE does not automatically send Gmail messages or automatically submit job applications.

Google data use

JCE uses Google user data only to provide the Gmail draft features described above. Google user data is not sold, used for advertising, or used to train generalized AI or machine-learning models.

JCE's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Read the Privacy Policy for the full disclosure of access, use, storage, sharing, retention, and user controls.

Access

This public site exists to provide transparent information about JCE and its data practices. The JCE application itself is private and restricted to authorized users.
