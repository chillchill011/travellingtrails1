# JCE OAuth public pages

This branch contains only the public Job Campaign Explorer OAuth disclosure pages intended for a separate Netlify site at `jce.travellingtrails.in`.

It is deliberately isolated from the Travelling Trails production branch (`main`).

Netlify setup:
- Repository: `chillchill011/travellingtrails1`
- Production branch: `jce-oauth-pages`
- Base directory: leave blank
- Build command: leave blank
- Publish directory: `.`
- Custom domain: `jce.travellingtrails.in`

Required Google Auth Platform values after deployment:
- Home page: `https://jce.travellingtrails.in/`
- Privacy policy: `https://jce.travellingtrails.in/privacy/`
- Terms of service: `https://jce.travellingtrails.in/terms/`
- Authorized domain: `travellingtrails.in`
